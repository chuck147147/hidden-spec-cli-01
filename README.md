# mend

mend applies AI-written edits in four formats — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of text files, exactly as SPEC.md specifies: three-tier line matching that tolerates drifted whitespace and indentation, and all-or-nothing writes so a failed patch changes nothing.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
